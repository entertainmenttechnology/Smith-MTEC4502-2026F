# Student Work Template

## How to Use This Folder

Each student should create a separate personal GitHub repository or another instructor-approved hosted workspace. Do not place your personal work folder inside the instructor course repository.

1. **Create a personal repository or workspace** named after you (e.g., `firstname-lastname-mtec-4502/` or your GitHub username)
2. **Use this structure in your workspace** for all MTEC 4502 assignments, reflections, and portfolio work
3. **Keep this folder organized** with subfolders for different assignments or project types
4. **Commit and push regularly** — your work is visible in version history

#### Example Structure (for your folder):

```
firstname-lastname-mtec-4502/
└──
    ├── assignments/
    │   ├── 01-career-strategy/
    │   ├── 02-career-visualization/
    │   ├── 03-portfolio-platforms/
    │   ├── 04-ai-portfolio/
    │   └── 05-resume-cover-letter/
    ├── reflections/
    ├── research-notes/
    └── portfolio-experiments/
```

#### Guidelines

- **All work is your responsibility** — this is your professional archive
- **Commit messages should be clear** — describe what you've changed and why
- **Privacy:** If you need to keep information private, use `.gitignore`
- **Feedback:** Instructors and peers will review your work through commits and pull requests

---

**Note:** Copy this structure into your personal workspace. The `student-work` folder in the course repository is a guide, not a submission location.
