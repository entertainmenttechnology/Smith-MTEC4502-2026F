# Session Notes

Chronological records of class sessions: meeting summaries, transcripts, and similar in-the-moment notes. Unlike the syllabus and slide decks (which describe planned content), this folder is organized by date and records what actually happened in each session.

File naming: `YYYY-MM-DD_short_description.md`

If a summary or transcript names a specific student in a way that isn't useful for the whole class (e.g., a personal circumstance, an attendance issue), redact or remove that detail before committing here — this folder is visible to the whole class.
