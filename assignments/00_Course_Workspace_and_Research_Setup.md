# Assignment 00: Course Workspace and Research Setup

**Course:** MTEC 4502 - Career and Portfolio Seminar  
**Due:** Week 1  

---

## Objective

Establish the personal workspace and research tools you will use throughout the semester. This setup creates a reliable home for your drafts, research, revisions, portfolio materials, and assignment links before Assignment 1a begins.

---

## Required Setup

### 1. Create Your Personal Workspace

Create a personal workspace for your MTEC 4502 work. A personal GitHub repository is strongly recommended because version-control practices are widely used in creative and technical industries; however, you may use a Google Drive folder, Dropbox folder, or another instructor-approved hosted workspace when appropriate. Do not create your personal work folder inside the course repository.

Use the [Student Work Template](../student-work/STUDENT-FOLDER-TEMPLATE.md) to create an organized structure for assignments, reflections, research notes, and portfolio experiments.

### 2. Register Your GitHub Account and Join the Course Repository

* Create or confirm access to a GitHub account.
* Submit your GitHub username privately through [Brightspace](https://brightspace.cuny.edu/d2l/home/1337499) by the Week 1 deadline.
* After the instructor confirms enrollment, accept the invitation to the private course repository.
* Do not post student IDs, private contact information, passwords, confidential client or employer material, or other sensitive information in the course repository or your public workspace.

### 3. Configure Your Workspace

* Organize the workspace using the required folder structure.
* If using GitHub, sign in to GitHub and GitHub Desktop or another Git client, create an initial `README.md`, and make an initial commit.
* Confirm that the instructor can access the workspace through a shareable link.

### 4. Configure Research Workflow

* Install [Zotero Desktop](https://www.zotero.org/) and the Zotero Connector browser plugin.
* Ensure you have a personal library and can access it.
* Join Zotero and create a user account. We will hook this up to the shared directory at class 2.  
* Save one test source to your personal Zotero library to confirm the Connector is working.

### 6. Begin Collecting Portfolio Materials

Begin gathering potential material from prior courses, personal projects, internships, employment, performances, productions, and collaborations. Create a working folder in your personal workspace for project files, images, videos, links, drafts, and notes.

This is an early inventory, not a final portfolio selection. Consider which materials show your skills, process, role, and professional direction. You will evaluate platforms and make portfolio selections later in the course.

### 6. Review Submission and Privacy Expectations

* Use your personal workspace as the working archive for process, drafts, and revisions.
* Submit formal assignments through the corresponding Brightspace submission link at [Brightspace](https://brightspace.cuny.edu/d2l/home/1337499).
* Use Brightspace for private course communications, sensitive information, grades, and any formal submission the instructor requests.
